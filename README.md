# 🎬 TTD - TikTok videos Downloader

> An enhanced version of [Hikari TikTok Downloader (made by Gary19gts)](https://github.com/gary19gts/Hikari-TikTok-Downloader).

| Main Interface                                               | Download History                                             | Auto Paste                                                   |

## Features

- Auto-paste TikTok URL
- Auto-fetch video title, support title renaming
- Support viewing download history
- Provide downloadable versions for different platforms



## How-To

```bash
# Run
git clone git@github.com:i0Ek3/ttd.git
cd ttd
python3 setup.py
python3 main.py

# Build & Pack
./build.sh
```
